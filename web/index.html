使用指南

如何让多台设备加入同一个房间？

在一台 Windows 或 Mac 电脑上启动近传并保持运行。其他电脑、手机和平板接入同一局域网，用浏览器打开主机显示的地址并输入连接码，也可以扫码加入。其他电脑直接加入已有房间即可。

怎样发给特定设备或整个房间？

在「收件人」中选一台设备，或点击设备列表中的发送图标。输入文字后点「发送消息」，也可以点「发送文件」多选文件。电脑支持直接拖入文件。选择「整个房间」时，新加入房间的设备也能看到保留的群发内容。消息和文件列表会注明发送和接收设备。

文件、安装包和视频保存在哪里？

主机把文件副本保存在用户的「下载 / WiFiDrop」目录。接收设备点击下载后，由浏览器保存。iPhone 可在「文件」App 的下载项中查找。近传会原样传输图片、视频、文档或 APK 等安装包。能否播放或安装取决于接收设备系统。

大文件中断后如何继续？

传输时尽量让浏览器保持前台。中断后点「继续」。如果已刷新或关闭页面，在原来的浏览器中选择相同收件人，再选择同一原文件，即可续传已确认的分块。可用空间、浏览器和文件系统会影响可传输的大小。

谁可以看到消息和文件？

单发内容显示在收发双方的页面，群发内容显示给房间成员。内容由房间主机中转和保存，主机的使用者可以访问磁盘上的内容。近传使用局域网 HTTP，请在可信网络中使用，并只向信任的人分享二维码和连接码。

设备连不上，或页面不再更新？

确认各设备连接同一路由器。主机可以使用网线，其他设备可以使用 Wi-Fi。尝试切换主机二维码下的局域网地址，检查本地网络权限、防火墙、VPN 和访客网络隔离。关闭主机浏览器后，后台服务仍会运行，点「退出近传」才会结束房间服务。

删除文件会影响哪些设备？

「删除」会移除主机保存的这份副本，接收设备将不能继续下载。发送时选择的原文件和已经下载的副本仍然保留。
