使用指南

多台设备如何加入房间？

在一台 Windows 或 Mac 电脑上启动近传并保持运行。其他设备连入同一路由器，用相机扫描主机「设备」页的二维码，或在浏览器打开显示的地址并输入连接码。

如何发送消息和文件？

在「消息」或「文件」里选择收件人，然后发送。选「整个房间」时，后来加入的设备也能看到保留的群发内容。电脑可以拖入文件，接收设备在「文件」里下载。

文件保存在哪里？

主机把副本保存在用户的「下载 / WiFiDrop」目录。接收设备的下载位置由浏览器设置决定。iPhone 可在「文件」App 中查看下载。图片、文档、视频与安装包都按原文件传输，播放和安装取决于接收设备。

大文件中断后如何继续？

保留浏览器页面，在文件的传输队列中点击「继续」。刷新后，可在同一浏览器里选择原收件人，再选择同一个文件，从已确认的分块继续上传。

谁可以看到消息和文件？

单发内容显示在收发双方的页面，群发内容显示给房间成员。房间主机负责保存消息和文件，可从磁盘访问这些内容。近传使用局域网 HTTP，请在可信网络使用。

设备连不上怎么办？

确认两台设备接入同一路由器。可切换主机二维码旁的局域网地址，并检查防火墙、本地网络权限、VPN 和访客网络隔离。要结束房间服务，请在主机的「设备」页点击「退出近传」。

删除文件会影响哪些设备？

删除后，接收设备无法继续下载主机上的这份文件。最初选择的原文件和已下载的副本仍会保留。
